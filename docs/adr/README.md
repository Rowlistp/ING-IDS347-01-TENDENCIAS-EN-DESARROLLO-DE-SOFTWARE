# Architecture Decision Records (ADR)

Este directorio contiene las decisiones arquitectónicas principales del sistema de validación de licencias postcuántico.

## ADR actuales

| ADR | Título | Estado |
|---|---|---|
| ADR-001 | Selección de ML-DSA como firma postcuántica principal | Propuesto |
| ADR-002 | Esquema híbrido ECDSA + ML-DSA | Propuesto |
| ADR-003 | Formato canónico de licencia y JSON Canonicalization | Propuesto |

## Regla

Cada ADR debe contener:
- contexto;
- opciones consideradas;
- decisión;
- consecuencias;
- riesgos;
- mitigaciones;
- criterios de aceptación.

Cuando una decisión cambie, el ADR anterior no se elimina. Se crea uno nuevo que lo sustituye o modifica.
