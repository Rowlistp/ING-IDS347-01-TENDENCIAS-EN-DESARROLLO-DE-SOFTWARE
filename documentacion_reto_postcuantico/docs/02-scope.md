# 02 — Alcance

## Dentro del alcance
- Generación de licencias.
- Firma digital clásica y postcuántica.
- Validación híbrida.
- Validación online.
- Validación offline.
- Expiración.
- Suspensión.
- Revocación manual.
- Revocación automática por reglas.
- Asociación usuario/licencia.
- Asociación opcional a dispositivo.
- Redirección mediante token temporal.
- API de licencias.
- Base de datos.
- Auditoría básica.
- Benchmark criptográfico.
- Pruebas de manipulación.
- Documentación técnica.

## Fuera del MVP
- Sistema de pagos.
- Facturación.
- DRM completo del ejecutable.
- Anti-debugging avanzado.
- Obfuscación avanzada.
- HSM empresarial.
- Alta disponibilidad multi-región.
- Blockchain.
- Inteligencia artificial.
- Desarrollo propio de algoritmos criptográficos.

## Principio de alcance
Primero se resolverá el núcleo de seguridad. El frontend será posterior al funcionamiento correcto de generación, firma, validación, expiración y revocación.
