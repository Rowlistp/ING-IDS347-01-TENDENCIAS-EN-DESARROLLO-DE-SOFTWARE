# Plataforma de Tickets Digitales e Inventario de Combustible

Proyecto academico para el desarrollo de una plataforma web y una aplicacion movil destinadas a la gestion de solicitudes de combustible, tickets digitales con codigo QR, despacho, inventario, trazabilidad, auditoria y reportes.
