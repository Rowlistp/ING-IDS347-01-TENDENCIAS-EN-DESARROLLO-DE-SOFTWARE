# Sistema de Validación de Licencias Postcuántico

Documentación base del reto de Tendencias en Desarrollo de Software.

## Objetivo
Diseñar e implementar un sistema de licenciamiento digital que permita generar, validar y revocar licencias, con soporte online y offline, incorporando criptografía postcuántica y una estrategia híbrida de transición.
